# HAPPY TEARS — FREAKTION SONG 002 / Phase 0 (30秒デモ × 3案)

ZIG のオリジナル曲「HAPPY TEARS（ハッピー・ティアーズ）」の、伴奏の違う 30 秒デモ3案。
試聴: [happy-tears.html](../../happy-tears.html) (`npm run dev` → `/happy-tears.html`)。A/B/C の切り替え、再生・停止、再生位置、ボーカル ON/OFF、**楽器別の音量** (6パート)、BPM・コード進行・リフ・歌詞の表示、試聴評価 (3項目の5段階 + メモ、ブラウザに保存・JSON に書き出し)。

> もうここにはいない人が残した音楽を、未来を生きる ZIG が今も聴いている。楽しくて笑ってしまう、でももう会えないと思うと悲しい。それでも音楽を残してくれたことに感謝している。EMOTION COLLISION × TIME CROSS — 喜びと悲しみ、過去と未来を同時に鳴らす

**この曲を悲しい追悼曲にしない。** 明るいオーケストラ (弦・ブラス・グロッケン) が鳴り続ける下で、チェロ・コントラバス・バスクラリネット・バリトンサックスが悲しい線を歌い、ドラムとベースは前へ走り続ける。HAPPY と TEARS は切り替えずに **同時に** 鳴らす。最後は明るい D で「ありがとう」が残る。
hide の作品から研究した原理は参考にしているが、既存曲の歌詞・旋律・リフ・歌声は使っていない。ZIG は hide を演じない。

### A — BRASS RIFF (160 BPM)

最もライブで盛り上がる。歪みギターとバリトンサックスが1つのリフを分け合う

| 時間 | 区間 | 内容 |
|---|---|---|
| 0.0–6.0s | イントロ | ギター (1–2拍) とバリトンサックス (3–4拍) が交互に1つのリフを作る |
| 6.0–12.0s | Bメロ | 「止まった時計が 酔っぱらって / 昨日と明日を 飲み干した」 |
| 12.0–24.0s | サビ | HAPPY〜! TEAR〜S! ×2 — 笑いながら空を見上げて / 泣きながら明日を鳴らす |
| 24.0–30.0s | ラスト | HAPPY〜! TEAR〜S! と「ありがとう」、明るい D で終わる |

**コード進行**

- 1–4 (イントロ): **D – A/C♯ – Bm – G→Gm** — 明るい I から下降ベース、最後の小節で G が Gm (同主短調からの借用 iv) に沈む
- 5–8 (Bメロ): **Bm – G – Em – A** — 酔っぱらった時計: 短調寄りで A に向かう
- 9–16 (サビ): **D – A/C♯ – Bm – G→Gm ×2** — Pattern A を元に、4小節目だけ G→Gm。「見上げて」の D を伸ばしたまま和音が一瞬だけ陰る
- 17–20 (ラスト): **D – A/C♯ – G→Gm – D** — 「ありがとう」の小節で Gm を通り、明るい D に着地

**リフ・編曲**

- **RIFF A — BRASS RESPONSE**: ギターが1–2拍に D5・m・D5・E5 を弾いて止まり、3–4拍の休符をバリトンサックスが A–C–D–A–D と埋める。サビでも TEARS の小節でサックスが答える
- **ストリングス**: サビの間ずっと、バイオリン (スピッカート) がコードの音を2オクターブ上で8分の上昇アルペジオ
- **チェロの嘆き**: サビの4小節ごとに D – C♯ – B – B♭ と半音ずつ下がる (明るい和音の下で泣き続ける)

**FREAKTION の発見**

- **サックスがギターの続きを弾く**: ギターの休符にバリトンサックスが入ると、2つの楽器で1本のリフに聞こえる (と設計した)。サビでも TEARS の伸ばしの下でサックスが答え、悲しい低音が「返事」になる

### B — ORCHESTRA RIOT (156 BPM)

幸福と悲しみが最も同時に感じられる。弦と金管が前、ロックバンドが下で走る

| 時間 | 区間 | 内容 |
|---|---|---|
| 0.0–6.2s | イントロ | ティンパニとロータムを軽く歪ませ、ギターと 3+3+2 で同時に叩く。ホルンがフックの形を先に吹く |
| 6.2–12.3s | Bメロ | 「止まった時計が 酔っぱらって / 昨日と明日を 飲み干した」 |
| 12.3–24.6s | サビ | HAPPY〜! TEAR〜S! ×2 — 笑いながら空を見上げて / 泣きながら明日を鳴らす |
| 24.6–30.8s | ラスト | HAPPY〜! TEAR〜S! と「ありがとう」、明るい D で終わる |

**コード進行**

- 1–4 (イントロ): **Bm – G – D – A** — Pattern B (悲しみから浮上)。短調から始まり、D・A で明るさへ上がる
- 5–8 (Bメロ): **G – D/F♯ – Em – A** — 下降ベース (G–F♯–E) の上で時計が酔う
- 9–16 (サビ): **Bm – G – D – A | Bm – G – D – G→Gm** — 同じフックを短調の Bm で始め、「泣きながら」の最後で G→Gm に陰らせる
- 17–20 (ラスト): **Bm – G – G→Gm – D** — 最後は長調の D に浮かび上がる

**リフ・編曲**

- **RIFF B — DISTORTED PERCUSSION**: ギターのパワーコードとティンパニ・ロータムを同じ 3+3+2 のリズム (0, 0.75, 1.5, 2.5, 3.25 拍) で同時に。打楽器は 200 Hz より上だけ歪ませ、低音はきれいなまま分ける
- **ストリングスとブラス**: サビは長い音のバイオリン・ビオラ・ソロバイオリン (高音)、TEARS の小節でトランペットのファンファーレ、各サビの頭でオーケストラヒット
- **悲しみの低音**: チェロとバスクラリネットが D – C♯ – B – B♭ の嘆きの線を1オクターブ違いで、コントラバスが和音の根音

**FREAKTION の発見**

- **歪んだティンパニ**: ティンパニの 200 Hz より上だけを歪ませると、低い胴鳴りはオーケストラのまま、アタックがギターのパワーコードと一体になる (帯域を分けた設計)

### C — BROKEN PARADE (158 BPM)

最も予想外で、もう一度聴きたくなる。行進曲が何度もつまずく

| 時間 | 区間 | 内容 |
|---|---|---|
| 0.0–6.1s | イントロ | 1つのフレーズが小節ごとに guitar → bariSax → pizz → image へ受け渡される (種 parade-03) |
| 6.1–12.2s | Bメロ | 「止まった時計が 酔っぱらって / 昨日と明日を 飲み干した」 |
| 12.2–24.3s | サビ | HAPPY〜! TEAR〜S! ×2 — 笑いながら空を見上げて / 泣きながら明日を鳴らす |
| 24.3–30.4s | ラスト | HAPPY〜! TEAR〜S! と「ありがとう」、明るい D で終わる |

**コード進行**

- 1–4 (イントロ): **D – F♯m – G – G→Gm** — Pattern C (未解決の幸福) をそのまま行進曲に
- 5–8 (Bメロ): **Bm – G – C – A** — C は D の ♭VII (同主短調からの借用)。酔った時計が一瞬違う調に迷い込む
- 9–16 (サビ): **D – F♯m – G – G→Gm | D – F♯m – Em7 – G→Gm** — 「空を見上げて」「明日を鳴らす」の最後で G→Gm
- 17–20 (ラスト): **D – F♯m – G→Gm – D**

**リフ・編曲**

- **RIFF C — MUTATING ORCHESTRA**: パレードのフレーズ (根音・3度・5度・6度…の8音) を、イントロの4小節で guitar → bariSax → pizz → image の順に受け渡す。4小節目は +1 半音ずれる。サビでは SONOVA の画像楽器 (rust → water) が答える
- **歪んだ打楽器**: 行進曲の裏拍でロータムを強く歪ませ (低域はそのまま)、スネアのロール
- **低音管楽器**: チューバのオンパ (VSCO) と、バリトンサックス・バスクラリネット (SONOVA 物理モデル)

**FREAKTION の発見**

- **つまずく行進曲**: 最後のフックの前 (16小節目の 3 拍目から) でバンドがテープストップしてつまずき、次の小節で何もなかったように立ち直る (種 `parade-03`、設定 `{"seed": "parade-03", "relay": ["guitar", "bariSax", "pizz", "image"], "materials": ["rust", "water"], "trip": 2, "bend": 1}`)

### 「HAPPY〜! TEAR〜S!」の音節設計

VOICEVOX はカナ1モーラを1音符で歌う。英語の HAPPY TEARS を次のように音符に割り当てた。

| 英語 | カナ | 長さ (拍) | 音 | 歌い方 |
|---|---|---|---|---|
| HAP | ハ | 0.5 | D4 | 強く短く。続く ッ は休符で表す |
| PY〜 | ピ | 2.5 | A4 | 完全5度上へ跳ねて母音 i を伸ばす (高揚) |
| TEAR〜 | ティ + ア | 2.5 | A4 → F♯4 → E4 | ティで当て、母音 a を伸ばしながら一段下がる (泣き声の揺れ) |
| S！ | ズ | 0.25 | E4 | 子音 z だけ。母音 u は消す (英語の末尾子音を伸ばさない) |

- HAPPY は「ハ」で強く当てて、完全5度上の「ピ」で母音 i を伸ばす (跳ねる・高揚)
- TEARS は「ティ」で当て、母音 a を伸ばしながら F♯4 → E4 と一段下がる (笑いながら泣く声の揺れ)
- 最後の S は **子音 z だけ** を鳴らす。VOICEVOX のカナ「ズ」は z+u なので、歌唱クエリの母音 u の音量を 2 フレーム (約 21 ms) で 0 にした。英語の末尾子音を「ズー」と伸ばさない
- **EMOTION COLLISION**: サビは ZIG の声 (VOICEVOX:玄野武宏 ノーマル) に、同じキャラクターの「喜び」と「悲しみ」の歌い方を左右に同時に重ねた。笑い声と泣き声が同じ旋律で鳴る。フックは白上虎太郎 (わーい) が1オクターブ上で重なる
- 「ありがとう」は重ねず、ZIG の声だけで、下降して主音に着地する

### 物理モデルの管楽器 (SONOVA で新しく作った)

VSCO-2-CE にはサクソフォンとバスクラリネットが無いので、SONOVA の `packages/orchestra-engine/src/reed.ts` にデジタル導波管の物理モデルを作った (STK の Clarinet / Saxofony モデルの考え方を参考に自作。STK のコードは使っていない)。

- バスクラリネット: 円筒管 = 1本の遅延線 (奇数倍音)、リードは圧力で開閉する弁
- バリトンサックス: 円錐管を、リードの位置で分けた2本の遅延線で近似 (全ての倍音)、胴の共鳴と少しの歪み (ホンク・グロウル)
- 音程は実測して遅延の補正値を決めた: G1–A3 の全音・強さ 0.4–1.0 で ±3 セント以内、オクターブ跳び (オーバーブロー) なし

本物の楽器の録音ではない。人が聴いて「サックスに聞こえるか」はまだ確かめていない。

## 再生成

SONOVA リポジトリ (https://github.com/Yuji5124/sonova, ブランチ `claude/serene-dijkstra-oizcm3`) で:

1. `npm run od:fetch` — VSCO-2-CE (CC0) のサンプルを取得 (`vendor/VSCO-2-CE`、Git 管理外)
2. VOICEVOX Engine 0.26.0 を起動 (`run --port 50021`、または VOICEVOX アプリを開いておく)
3. `npm run happytears -- --out <このリポジトリのパス>` — 約3分。曲の中身は `packages/composition-engine/src/series/happytears.ts`、レンダリングは `scripts/happytears.ts`
4. 歌の音程・タイミング (VOICEVOX の歌唱クエリ) は SONOVA の `experiments/happytears/vocal-queries/` に固定してあるので、同じ楽譜なら同じ歌になる
5. C の変異は `demoHappyC('<種>')` の種で変わる。`demos.json` の `paradeSeeds` に6つの種の設定を保存した

## 検証 (この時点)

- 3案とも 30.2–30.9 秒、−14.0 LUFS、ピーク −1 dBFS 以下、クリップ・無音なし
