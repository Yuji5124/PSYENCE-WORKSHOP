# PSYLO — Phase 1: VOCAL IMPLEMENTATION

**Status (2026-10-24):** A案の8小節を、日本語の歌声 (歌詞付き) がギター・ベース・ドラムと同期して歌う。ブラウザで歌声 ON/OFF・A/B/C の歌い方・歌詞の2版・2つの声を切り替えて試聴できる。

> 歌声: **VOICEVOX:波音リツ** / **VOICEVOX:玄野武宏** — VOICEVOX Engine 0.26.0 の歌唱 (ソング) 機能で生成。

## 1. 採用した歌声合成方式: VOICEVOX Engine (ソング)

| 候補 | 調べたこと | 判断 |
|---|---|---|
| **VOICEVOX Engine** ([VOICEVOX/voicevox_engine](https://github.com/VOICEVOX/voicevox_engine), 0.26.0) | 歌唱 API `/sing_frame_audio_query` → `/frame_synthesis`。楽譜は `notes: [{key: MIDI, frame_length: フレーム数 (93.75 fps), lyric: カナ1モーラ}]`、最初のノートは無音。CPU で動作 (GPU は任意)。Windows/macOS/Linux の CPU 版あり。WAV を返す | **採用**。12 テイクを CPU だけで約 30 秒で生成。歌詞を音素 (例 `sh o`, `r o`) に分けて、音符の頭に母音が来るよう子音を前に置いてくれる |
| [OpenUtau](https://github.com/openutau/OpenUtau) | MIT。UTAU / ENUNU 系の歌声ライブラリ、UST/MIDI 読み込み。リポジトリにはコマンドラインや一括書き出しの記載が見つからなかった (GUI 中心)。歌声ライブラリごとに別ライセンス | 第2候補として保留 (自動化しにくい) |
| [DiffSinger](https://github.com/MoonInTheRiver/DiffSinger) | MIT。PyTorch、要求環境は CUDA の GPU 前提 (2080Ti / 3090 用の requirements)。日本語の事前学習モデルの記載なし | 不採用 (GPU 前提・モデルの入手と権利が不明) |

### 歌い手 (スタイル) の構成

- **音程・タイミング・音素を作る (クエリ)**: 歌唱スタイル `6000` = 波音リツ ノーマル (`type: sing`)。VOICEVOX で歌唱スタイルを持つのは現時点で波音リツだけ
- **声 (合成)**: `frame_decode` スタイルなら誰でも可。今回は
  - **波音リツ ノーマル (3009)** — 歌声として作られた声。原調 (サイ D5–E5 → ロー F#5)
  - **玄野武宏 ノーマル (3011)** — 男声。原調では高すぎるので **1オクターブ下** (ロー F#4)
  - 青山龍星は企業が関わる利用に事前確認が必要なため使わなかった

## 2. 歌詞と音符

- 元データ: [`src/psylo-vocal.json`](../../../src/psylo-vocal.json) — 各音符に `lyric` (カナ1モーラ)・`reading` (読み)・`midi`・`start` (拍)・`dur` (拍)・`vel`
- 対応表 (音素・原案との比較・母音の位置のずれつき): [notes.md](notes.md)
- **FULL**: 草案の言葉をほぼ全部、8分音符で駆け抜ける (48音)。「変なままで」は8小節に入らないので外した (サイローを最後にするため)
- **SHORT**: 言葉を減らし、行の後ろに息継ぎとギターの隙間を作る (30音)
- 日本語の扱い: 促音「ッ」= 直前の音を短く切って休符 (ポケ|ト、ヒ|ク)、長音「ー」= 長い1音 (ショ 1拍、ロ 2拍)。エンジンは「ー」を歌詞として受け付けない
- **サイロー**: サ D5 (7小節3拍、1拍、子音 s をはっきり) → イ E5 (7小節4拍から約3拍、上昇して次へつなぐ) → ロ F#5 (8小節3拍、子音 r で最高音に到達し、母音 o を2拍保持)
- 原案からの変更: フックの3音 (D5・E5・F#5) と各拍の骨格は原案どおり。言葉を乗せるために拍の裏 (8分) に音を足し、FULL の3小節目の最後を B4 に、7小節目の頭を「さあ」から「光れ」(A4・A4・B4) に変えた。ブラウザの GUIDE で「原案メロディ」と「歌唱版メロディ」を聴き比べられる

## 3. 歌い方 A / B / C (エンジンの機能だけで作った差)

VOICEVOX のクエリ (フレームごとの f0・音量、音素ごとの長さ) を書き換えてから合成している。エフェクトは使っていない。

| | 中身 |
|---|---|
| **A / STRAIGHT** | エンジンの出力そのまま |
| **B / ROCK** | 子音を約30%長く (前の音素から借りるので全体の時間は変わらない)、音節の入りを +3 dB、短い音符の後ろ30%を絞って跳ねさせる |
| **C / WILD** | 音の入りを下から (−1.5半音→0、64 ms) すくう、1拍以上の音にビブラート (±35セント・5.6 Hz、150 ms 後から)、句の終わりで音程を落として切る (−2半音・120 ms)、小節頭のアクセント |

## 4. 演奏との統合

- 歌声は事前生成の WAV。ブラウザでは AudioContext の同じ時刻軸に置く: ファイルの `lead_seconds` (0.8 秒) の位置が1小節目1拍目と一致するように `start(when, offset)` する (子音のために 0.25 秒前から再生)
- 楽譜からフレームへの変換は「絶対時刻を丸める」方式なので、丸めの誤差 (最大 ±5.3 ms) が小節を重ねても溜まらない。実測: 全音符の母音の位置は ±5 ms 以内 ([notes.md](notes.md))
- 歌声が ON の間は 160 BPM に固定 (歌声は 160 BPM で生成しているため)
- 歌声の処理: ハイパス 110 Hz → 軽いコンプ (−20 dB, 3:1) → 3 kHz +2.5 dB → 110 ms のスラップ
- ギター: FreePats のサンプルギターはそのまま。**サ から −2 dB、ロー の間 −3 dB** 下げてフックを前に出す
- ベース: キックのたびに 90 ms だけ −7 dB 下げる (キックとベースがぶつからないように)
- マスター: 既存のコンプのあとに速いリミッター (−2.5 dB) を追加。歌声を足したミックスがクリップしないように (修正前のピーク 0.0 dBFS → −1.4 dBFS)
- 各パートの音量スライダー (歌声・ギター・ベース・ドラム)

## 5. 再生成の手順

1. VOICEVOX Engine 0.26.0 以降をダウンロードして起動
   - Windows: [Releases](https://github.com/VOICEVOX/voicevox_engine/releases) の `voicevox_engine-windows-cpu-<version>.7z.001` (または `.vvpp` = zip) を展開し `run.exe` を実行
   - Linux: `voicevox_engine-linux-cpu-x64-<version>.vvpp` (約 1.9 GB の zip) を展開し `./run --port 50021`
   - VOICEVOX アプリ (エディタ) を起動しているだけでもエンジンは `127.0.0.1:50021` で動いている
2. `npm run vocal:render` — `public/audio/psylo/vocal/` に 12 テイク (2声 × 歌詞2版 × 歌い方3) と `manifest.json`・`timing-*.json` を書き出す (約30秒)。別のポートなら `VOICEVOX_URL=http://127.0.0.1:50021`
3. `node tools/psylo-vocal-table.mjs` — 対応表 [notes.md](notes.md) を更新
4. `npm run dev` → `/psylo.html`

エンジン本体 (約 2 GB) はリポジトリに入れない。生成した WAV (24 kHz / 16-bit / mono、1本 約 650 KB、合計 約 7.8 MB) はブラウザで再生するためにリポジトリに含めた。Git LFS は既存の運用にないので使っていない (これ以上増えるなら LFS かリリース添付を検討)。

## 6. ライセンスとクレジット

- **VOICEVOX Engine**: LGPL v3 と別ライセンスのデュアルライセンス。エンジン利用規約: 商用・非商用可、生成した音声は各音声ライブラリの規約に従う、**VOICEVOX を利用したことがわかるクレジット表記が必要**。エンジン本体は同梱していない
- **波音リツ**: 「**VOICEVOX:波音リツ**」とクレジットすれば商用・非商用で利用可 (詳細 http://canon-voice.com/kiyaku.html)
- **玄野武宏**: 「**VOICEVOX:玄野武宏**」とクレジットすれば商用・非商用で利用可 (詳細 https://www.virvoxproject.com/voicevoxの利用規約)
- 公開・配布するときは、上のクレジットを曲の説明に必ず書く。試聴ページにも表示している
- 実在の歌手の声は使っていない (hide 本人の声の再現もしていない)。歌詞・旋律はオリジナル

## 7. 試聴結果 (この時点の確認)

この作業をした Claude は音を耳で聴けない。以下は測定とブラウザでの動作確認。**「サイロー！」と口ずさみたくなるかは、まだ人が聴いて判断していない**。

- ヘッドレス Chromium で /psylo.html を開き、A案を歌声つきで最後まで再生: 歌詞のハイライトが音節ごとに進み、「サイロー」の区間表示が点灯。ページのエラーなし (ファビコンの 404 のみ)
- 同じスケジュールをオフラインで書き出し (48 kHz) て測定:
  - 歌声の音程: サ 74.0 / イ 76.3 / ロ 78.2 (MIDI、予定 74 / 76 / 78)。全体で ±0.3 半音以内
  - 歌声とバンドの比 (1–4 kHz): 1〜6小節 +2.7 dB、**ロー +3.9 dB** (200 Hz–1 kHz では +8.6 dB)。ロー の F#5 は周辺より 47 dB 突き出ている
  - 「イーー」の区間は 1–4 kHz で −1.3 dB (ギターの高域にやや負ける。音程の帯域 200 Hz–1 kHz では +4.0 dB)
  - ピーク −1.4 dBFS、クリップなし

## 8. 未解決の課題

1. **イーー の明瞭さ**: 長い「イ」の高域がギターと重なる。ギターの 2–4 kHz を歌の間だけ削る、または「イ」の音量を上げる
2. **FULL の密度**: 1秒に約5.3音節 (8分音符)。歌えるか、言葉が聞き取れるかを人が聴いて確認する。SHORT との比較で決める
3. **男声**: 玄野武宏は1オクターブ下で歌わせている。「ロー」の高揚感が下がるので、キーを上げる/リツと重ねる (2声) を試す
4. 「変なままで」の置き場所 (次の8小節・2番)
5. 歌唱スタイルが波音リツ1種類しかないため、音程の動き (しゃくり・ビブラートの癖) はどの声でもリツ由来になる
