# NOBODY ON AIR — FREAKTION SONG 001 (30秒デモ × 3案)

ZIG のオリジナル曲「NOBODY ON AIR（ノーバディ・オンエア）」の、方向の違う 30 秒デモ3案。
試聴: [nobody.html](../../nobody.html) (`npm run dev` → `/nobody.html`)。A/B/C の切り替え、再生・停止、ボーカル ON/OFF、再生時間、3案の違い、試聴メモ (ブラウザに保存・JSON に書き出し)。

**FREAKTION = FREAK × REACTION** — 異質な音をぶつけ、予想していなかった音楽を見つける。ただし最後は口ずさめるフックに着地させる。
既存曲のリフ・歌詞・旋律・歌声は使っていない。hide 本人の声も再現していない。

## 歌声

- **VOICEVOX Engine 0.26.0 の歌唱機能** (`/sing_frame_audio_query` → `/frame_synthesis`、CPU)。読み上げ音声のピッチ変更ではなく、楽譜 (カナ・MIDI 音高・長さ) から歌わせている
- 音程とタイミングは VOICEVOX で唯一の歌唱スタイル **VOICEVOX:波音リツ** が作り、声を各キャラクターに差し替える。各母音の音程を楽譜へ 75% 寄せて揺れをならす安定化を入れた (SONOVA `scripts/lib-voicevox.ts`)
- 「NOBODY! NOBODY! ON AIR!」は **カタカナで歌っている** (ノ・バ・ディ / オ・ン・エ・ア)。英語の発音ではなく、日本語の音として歌う (VOICEVOX は日本語のカナしか歌えない)
- A: 玄野武宏 (ツンギレ/ノーマル) + 白上虎太郎 (おこ, 1オクターブ上)、B: 白上虎太郎 (ふつう) + (わーい, 3度上のハモり)、C: 雀松朱司 + 剣崎雌雄 + 白上虎太郎 (おこ) + 麒ヶ島宗麟 (ロボット声)
- 公開するときは各キャラクターのクレジット (上の各案) を必ず表記する

## 再生成

SONOVA リポジトリ (https://github.com/Yuji5124/sonova, ブランチ `claude/serene-dijkstra-oizcm3`) で:

1. VOICEVOX Engine 0.26.0 を起動 (`run --port 50021`、または VOICEVOX アプリを開いておく)
2. `npm run nobody -- --out <このリポジトリのパス>` — 約2分半。曲の中身は `packages/composition-engine/src/series/nobody.ts`、レンダリングは `scripts/nobody.ts`
3. 歌の音程・タイミング (VOICEVOX の歌唱クエリ) は毎回少し変わるので、SONOVA の `experiments/nobody/vocal-queries/` に固定して保存している。同じ楽譜なら同じ音になる (2回生成して同一の WAV を確認)
4. C の突然変異を変えるには `nobodyDemos('<種>')` の種を変える (`freaktionSearch` の候補を参照)

## 使った SONOVA の機能

- ロックのレンダラー (`renderRock`): 弦の物理モデル (Karplus–Strong + WDF ダイオードクリッパーのアンプ + キャビネット) の左右2本のギター・ベース・リード、モード合成のドラムキット、セクションごとの音量、リバーブ、マスター
- 弦モデルをクリーンアンプで鳴らすアルペジオ (`renderRig`、B)
- 画像楽器 v1.1 (`analyzeImageV11` → `createImageDNAV11` → `renderVoice`、B の鐘と C の電子音) と相互作用の生成器 v1.1 (`generateV11`、C)
- バイトビート (`renderBytebeat`)、glitch (`glitch`)、メガホン・ロックボーカルの処理 (`megaphone` / `rockVocal`)、ラジオ化 (新規 `radioize` / `radioStatic`)
- VOICEVOX の歌唱 (`singLine`、音程の安定化つき)、ラウドネス測定 (BS.1770, `loudness`)

## 検証

- 3案とも 30.0 秒、ピーク −1 dBFS 以下、クリップなし、無音部分なし (SONOVA `verifyAudio`)。歌あり −14.0 LUFS
- ギター (左右)・ベース・ドラムの各パートが鳴っていることをレンダラーのステムで、歌がサビで楽器より前に出ていることを周波数帯の比較で確認 (1–4 kHz で A +2.9 dB、B +5.5 dB、C +0.6 dB)
- ヘッドレス Chromium で A/B/C の切り替え・再生・ボーカル ON/OFF・時間表示・メモの保存 (再読み込み後も残る) を確認。コンソールエラーなし、スマホ幅 (390 px) で横スクロールなし
- テスト (`npm test`) とビルド (`npm run build`) が通る

## まだ確かめていないこと

- 作業した Claude は音を聴けない。「もう一度聴きたくなるか」「C の突然変異が面白いか」は人が聴いて判断する
- SOUNDVAULT への登録はしていない (この作業環境から SOUNDVAULT のリポジトリに書き込む権限がない)。登録する場合は3案を別バージョンとして `demos.json` の情報で登録できる
